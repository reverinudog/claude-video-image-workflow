# 教訓：レビューツールの画面をいじる

## 動きの終わりを `animation.finished` で待たない
Claude の Browser ペインが隠れていると、ページの動きが止まり `el.animate(...).finished` がいつまでも終わらない。スワイプで削除する処理を「払う動きが終わったら」にしていたら、削除が発動しなかった（見えていないタブに切り替えた人でも同じことが起きる）→ 動きの後の処理は `setTimeout(動きの長さ)` で進める。動きはただの見た目にする。

## スマホ幅で1つでも横にはみ出すと、画面全体が縮む
上のバーのボタンを大きくしたら幅 375px に収まらず、ページ全体が縮んで表示され、`position: fixed` の「メモを書く」画面まで横にはみ出した（保存ボタンが画面の外）→ スマホ幅で `document.documentElement.scrollWidth === innerWidth` を JS で確かめる。はみ出している要素は `getBoundingClientRect().right > innerWidth` で探せる。保険として狭い画面では `html, body { overflow-x: clip }`。

## 定期的に描き直すと、中の動きが毎回やり直しになる
3秒ごとの問い合わせのたびに依頼欄を innerHTML で作り直していたら、進み具合の線が伸びる動きが3秒ごとに繰り返された → 描く中身の指紋（状態・件数などをつないだ文字列）を覚えておき、変わったときだけ描き直す（review.js の `reqSig`・`lastSendSig`、common.js の `mountPicker`）。

## Browser ペインでスマホ幅を試すときの注意
- スクロールしたページのスクリーンショットは上が空白で写るなど正しく出ない → スクロール位置 0 で撮るか、JS で要素の位置・クラス・値を調べる
- 指の操作は `new PointerEvent(..., { pointerType: "touch" })` を送って試せるが、`setPointerCapture` が例外を出して処理が途中で止まる（本物の指では出ない）→ 実装側で `try { el.setPointerCapture(id) } catch {}` にしておく
- 「/」キーは computer の key 操作では届かないことがある（JIS 配列）→ `dispatchEvent(new KeyboardEvent("keydown", { key: "/" }))` で試す

## 画像レビュー（/image）を足したとき（2026-10-06）
- **動かして確かめるのは試験用の作業フォルダで**
  - 起きたこと：最初の動作確認を本番の画像でやり、テストのメモが本番に残った（消す操作は権限で止まった）
  - 対処：`node review-tool/server.mjs --port 5179 --root <試験用> --inbox <試験用>/inbox`。Claude 側も `REVIEW_ROOT`・`REVIEW_INBOX` を同じ場所に向けて `listen.mjs --once`・`claude.mjs` を流す
- **同じ絵の .png と .jpg を1つとして扱うなら、結び付ける所すべてで拡張子を外して比べる**
  - 起きたこと：一覧は .jpg だけ出すのに、完了のとき .png を渡すと「新しい版」が出ず、新しい版を開いても依頼が見えなかった
  - 対処：画面は `canon()`、サーバーは `reqIsFor()` で読み替える
- **画面の一部を作り直さない最適化は、「何の画像のものか」も鍵に入れる**
  - 起きたこと：全体へのひとことが、別の画像へ移っても前の画像の文のまま残った（入力欄が残っていればその値を使う作りだった）
- **消したものを「元に戻す」ときは、番号も戻す**：サーバーが常に新しい番号を振っていて、戻すと番号が変わった
- **待っている間に画像を切り替えられる前提で書く**：保存・送信・Claude の状態の取得は、始めたときの画像を覚えておき、返ってきたときに今の画像と違えば画面に混ぜない
- **書きかけは捨てない**：メモを書いている途中で別の所を押す・画像を切り替える・送る、のどれでも先に保存する
- **画像を枠に収めるのは `container-type: size` と `100cqw / 100cqh`**：`100dvh` から決め打ちで引くと、進み具合の帯が出たとき下がはみ出した。スマホ（縦に流す配置）では高さが決まらないので `inline-size` にして `max-height` を別に決める
- **一覧の小さい絵は `<img loading="lazy">`**：背景画像にすると、数MBの絵を一覧の件数ぶん一度に読み込む。ファイル名に `'` や `)` があっても壊れない
- **Browser ペインが隠れているとスクリーンショットが返らないことがある**：そのときは PointerEvent を JS で流して、結果を数値で確かめる（`setPointerCapture` は合成イベントだと失敗するので try で囲んでおく）
