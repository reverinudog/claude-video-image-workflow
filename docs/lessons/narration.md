# 教訓：ナレーション

## 語尾切れの主因は「採用区間の終わりが早い」
無音詰めの閾値より、EDLの終了秒が語尾の減衰前で切れていることが多かった（製品紹介動画で4か所）。`tighten.py` の `extend()` で区間の端を -52dB を下回るまで最大0.3秒自動で伸ばす。指摘がなくても、書き出したナレーションを再度文字起こしして語尾を確認する。

## 無音詰めは強くしすぎない
-42dB／0.14秒で詰めたらぶつ切りになった。-50dB、0.34秒を超える無音だけ0.2秒に縮め、ブロック間は0.5秒残す、が適正だった。

## Whisperの幻聴と言い直しの断片
無音部分に「ご視聴ありがとうございました」、同じ語の繰り返しが出ることがある。VADありで取り直し、怪しい箇所は波形（RMS）で実際に声があるか確かめる。採用区間の直前直後に言い直しの断片（「しかも4」など）が紛れやすいので、境界はRMSで見て決める。

## 音量はテイクごとに±2dB程度ずれる
全体の loudnorm だけではテイク間の差が残り、「ここだけ大きい」と指摘された。`work/level.py`（テロップ区間ごとのLUFSを中央値へ85%寄せる）で±1.7dB → ±0.7dB になった。

## ナレーションを差し替えるときは map を版番号付きで残す
`narration_map.json` を上書きすると旧→新の時間の付け替え（remap）ができなくなる。`narration_map_vN.json` として保存してから作り直す。

## CUDA版 faster-whisper の DLL
`cublas64_12.dll` が見つからない場合：`pip install nvidia-cublas-cu12 nvidia-cudnn-cu12` し、スクリプト冒頭で `site-packages/nvidia/*/bin` を `os.add_dll_directory` と PATH の両方に足す（transcribe.py 参照）。
