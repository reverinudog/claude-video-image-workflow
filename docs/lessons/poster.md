# 教訓：静止画（ポスター・ロゴ）

## HTML を Chrome headless で等倍書き出しするとき
- **大きなぼかしは Chrome に任せない**
  - 起きたこと：数百pxの box-shadow・drop-shadow・blur を使うと、ソフト描画がタイルごとに描くため、暗部に四角い階調の段差が出た
  - 対処：光やにじみは Python（numpy/scipy）で float のまま作り、ディザを掛けて8bitの画像にして貼る
  - 確認方法：暗部は `-level 0%,30%` で持ち上げてから見る
- **普段の Chrome と設定フォルダを分ける**
  - 起きたこと：同じプロファイルを使っていたら、書き出しが返ってこなくなった
  - 対処：`--user-data-dir=<一時フォルダ>` を付ける（`templates/poster-html/render.mjs`）

## 素材
- **渡された画像は縮小版のことがある**
  - 起きたこと：チャットの添付は長辺2000pxに縮んでいた
  - 対処：`<素材フォルダ>` を縦横比で絞って探し、縮小して差分を取ると元データが見つかる（平均差2前後なら同じ絵）
  - 大きく使う前に必ず探す
- **背景抜きの縁の白いフチは、拡大すると点線になる**
  - 起きたこと：小さい透過画像を9倍にしたら、髪の輪郭に白い点々が出た
  - 対処：縁の画素の色を内側の不透明な色で塗り直し、アルファを1px強内側へ削る（`templates/poster-html/defringe.py`）

## 2人の顔を中央で合わせる（半分ずつの顔）
- 鼻筋を境目の線に合わせる。そのうえで、目の高さとあご先の高さの2点で倍率と位置を決める
- あごは「あご先」ではなく「境目の線の位置での輪郭の高さ」で合わせる。顔が傾いていると、この2つは100px以上ずれる
- 元画像で測った座標から換算すると、切り抜きの余白でずれる。書き出した画像の上で測って直す

## 直し方
- 「〇〇が見えない」と言われたら、その部分だけ直す
  - 起きたこと：「首下が見えない」に全体を明るくして応えたら、「まぶしすぎ、首下だけ直してほしかった」と言われた
  - 対処：その範囲だけを楕円マスクで持ち上げる
- 作字を座標で直接描くと素人っぽくなる
  - 方向は画像生成で幅広く出して選んでもらう
  - 選ばれた方向を、直線・矩形など正確に組める形でベクターに描き直す

## 配信告知のポスター・サムネ
- **登場人物を足す前に、ネタバレの線引きを聞く**
  - 起きたこと：対戦相手を並べた第一稿に「ネタバレのないように」と言われ、入れる・外すを3往復した（最後は主催者だけ）
  - 対処：プレイヤー本人が見る前提で、出してよい人物を最初に1問で確かめる
- **赤は明るい朱赤にしない**
  - 起きたこと：「目が痛い。ロゴの元の赤ぐらいで」と言われた
  - 対処：ロゴの色を測って基準にする（例：0.63, 0.10, 0.19）。背景・敵・光もその深紅へ寄せる（`crimson()`）
- **下を黒いグラデーションで塗りつぶすと安っぽい**
  - 起きたこと：題字を読ませるために下3割を黒へ落としたら「チープ」。乱数の煙を黒に混ぜても変わらなかった
  - 対処：地面を見せ、主役の足元は場の色（赤い砂煙）に溶かす。暗く落とすのは題字の後ろだけにして、ふちを乱数で崩す
- **ロゴの下に読みやコピーを足すと「文字を置いただけ」になる**
  - 起きたこと：明朝で題名の読みを足す → ロゴと同じ書体で読みだけ足す → どちらも不要、と3版かかった
  - 対処：ロゴにないものは足さない。題字の下は日時と出演の1行だけ
- **コピーは1か所、台本の言葉から、大小をつける**
  - 起きたこと：自作のコピー2つ＋公式のコピーを置いたら「微妙」「浮いてる」。同じ大きさの明朝で並べたら「安っぽい」
  - 対処：導入文から1つ選ぶ。要の言葉を大きく、助詞を小さく。欠け・かすれは読める強さまで（`distress(amount=0.5)`）
- **「見出し」の小さい字を暗い色にしない**：暗い地に赤い「進行」「主演」は読めなかった。白寄りにする
- **透過ロゴは薄い影つきのことがある**：切り抜くと暗い所で四角い縁が見える。アルファの薄い所（0.4 未満）を落とす
- **迷っている演出は、足した版と並べて見せる**：「雰囲気を足す？」には別版（v9b）を作って左右に並べた画像を渡した。差が小さいと分かってすぐ決まった
- **PIL の縦組み**：`direction="ttb"` は使えない。1字ずつ中央ぞろえで置き、「、。」は右上へ寄せて送りを 0.7 字ぶんにする（`vertical_var()`）
