# 教訓：Remotion（見た目）

## 吹き出しのしっぽ
3回指摘を受けて落ち着いた形（`Overlays.tsx` の Captions）：
- 背景は不透明にする（半透明だと、しっぽと本体が重なる部分が透ける）
- しっぽは付け根を塗りだけで描いて枠線を隠し、両辺だけ線を引く（全周に線を引くと食い込んで見える）
- しっぽは吹き出しの**縦中央**に置く。下からの固定位置だと、1行の吹き出しで上の角の丸みにかかって崩れる

## 最後のフェードは画面全体にかける
シーン単位でフェードすると、上に重ねている立ち絵やテロップだけが残る。本編の最上位に黒のオーバーレイを置いて全体を暗転させる（Main.tsx の EndFade）。

## ズームと注釈
- 注釈（矢印・枠）をズームするコンテナの中に置くと一緒に縮む。ズームの外に置き、座標だけ変換する
- 「ここを拡大」は指定点を画面中央に持ってきて、はみ出さないよう clamp する（端の点だと見切れた）

## モザイクは素材に焼き込む
CSSの blur をかぶせる方式は、分割表示や拡大でずれて中身が見えた。ffmpeg（crop → 縮小 → neighbor拡大 → overlay、動く物は時間で区切る）でプロキシ自体に焼き込む。

## 実寸比較
公式寸法がない製品は、同じ画面の寸法がわかる物（コンセントの刃、公式寸法のある旧機材）から px/mm を推定し、両方を同じ縮尺にそろえる。カメラに近い物は大きく写るので、写真の見た目のサイズを信じない。

## 確認は静止画 → 書き出し
書き出しは4分で約10分かかる。直したら `check.mjs` で該当秒の静止画を出して見てから書き出す。自分で確認していない見た目の修正を「直った」と言わない。

## 外部の canvas 描画エンジンを載せるときは Math.random を固定する
Remotion は複数の画面で並列にコマを描く。エンジンが模様（紙・粒子など）を `Math.random` で作っていると、画面ごとに模様が変わってちらつく。描画器の生成時と描画時だけ乱数を固定シードに差し替える（lyric-motion の `withSeededRandom`）。

## ぼかした光は「切り抜いてからぼかす」
`clip-path` と `filter: blur` を同じ要素にかけると、ぼかしたあとに切り抜かれてふちが鋭く残る（照明の筋が「線がはっきりしすぎ」と2回指摘された）。内側の要素で `clip-path`、外側の要素で `blur` にする。

## 光沢（動くグラデーション）は見えている範囲にかける
画面の外まで続く縦長の立ち絵の箱全体にグラデーションをかけると、帯の％が箱全体基準になり、見えている上半分を一瞬で通り過ぎる（「何か光った？」）。見えている範囲の大きさの箱にかけ（`mask-size` で立ち絵に位置合わせ）、帯が動く範囲を体の幅に合わせる。光は縮小の一覧だと見えないので、原寸に近いコマで確かめる。

## マスクは影も切る
`WebkitMaskImage` は要素の外に出る `box-shadow` まで消す。動いている間だけマスク（縁を溶かす）をかけていたら、止まってマスクを外した瞬間に影が急に出て「くっつくとシャドウが強くなる」と言われた（書籍のトレーラー v11）。マスクを付け外しする要素には影を付けないか、影を別の要素にする。

## 横に流すノイズの折り返しは固定の長さに
霧（feTurbulence）を `left: -(t * 速さ) % 周期` で流すとき、周期を画面の幅にしていたら、縦画面（幅1080）では数秒で折り返し、模様が一瞬で飛んだ（書籍のトレーラーショート v2「謎に背景が変わる」）。周期は固定の長さ（1152px）にして、場面の長さの中で折り返さないか確かめる。隣り合うコマの差を数字で比べると見つけやすい。

## 文字ごとに大きさが違う行の字間は、親の文字サイズで決まる
`letterSpacing: "0.03em"` を親の div に書くと、em は親の文字サイズ（指定しなければ16px）で px に確定してから子へ引き継がれる。1文字ずつ `fontSize` を変えた span を並べても字間は広がらない。打ち消すときも px（`spacing * 16`）で。

## 金のグラデーション文字に textShadow は使えない
`background-clip: text`＋`color: transparent` の文字に `textShadow` を付けると、影がグラデーションの上に描かれて濁る。影は親に `filter: drop-shadow(...)` で付ける。

## 動画を何十枚も同時に並べる場面は、書き出しの設定を軽くする
OffthreadVideo を20枚並べる場面（画面の壁）で `--concurrency=4` だとフレームの待ち時間切れになった。`--concurrency=2 --offthreadvideo-cache-size-in-bytes=1500000000 --timeout=240000` で通った。


## Node から renderMedia を呼ぶと、そのフォルダに .remotion/（書き出し用ブラウザ 約200MB）ができる
`motion-kit/tools/catalog.mjs` を作業フォルダの一番上で動かしたら `.remotion/chrome-headless-shell/` ができ、`git add -A` で入って push が「100MB超え」で止められた（2026-10-04）。`.gitignore` に `.remotion/` を入れてある。コミット前に `git status --short` で大きいフォルダが入っていないか見る。
