# レビューツール

動画を見ながら気になった場面に**時刻つきのメモ**（画像・書き込みつき）を残し、まとめて **Claude（Claude Code）に直してもらう**ためのツールです。ポスターやサムネなどの**静止画のレビュー**と、動画を作る前の**構成メモ**（全体の流れを1行ずつ並べたもの）の添削もできます。

- **動画レビュー**（`/`）：再生 → 止める → `M` でその場面の画像と一緒にメモ。画像には矢印・四角・丸・手書きで印を付けられます。「Claudeに送る」で依頼すると、進み具合と Claude の返事、直した新しい版がそのまま画面に届きます。前の版のメモと見比べて「直ってた」を確かめることもできます
- **画像レビュー**（`/image`）：ポスターやサムネなどの静止画に、**場所つきのメモ**を付けます。直したい所をなぞると範囲、押すと点。そのままひとこと書いて「送る」。Claude には番号の印を描き込んだ全体図と、場所（「右上」・割合・画素）が一緒に届きます。版ボタンで版を切り替え、「前の版」を押している間だけ前の版と見比べられます
- **構成メモ**（`/plan`）：1行ずつ書き換え・並べ替え・行ごとのコメント。変えたところは印が付き、「変更を表示」で元の文と見比べられます。自動で保存され、Claude が書き換えたら画面も自動で読み直します
- **演出カタログ**（`/catalog`）：motion-kit の部品（文字の入り方・効果・つなぎ・背景・テロップなど）を短い動画で一覧し、効果音はその場で鳴らせます。分類・検索で絞り込み、押すと大きく見られます（← → で前後へ）。データは `motion-kit/catalog/data.json`（`node motion-kit/tools/catalog.mjs` で作り直す）。見るだけのページで、書き込みはしません

スマホでも同じ画面で使えます（幅 820px 以下は縦1列）。

## 必要なもの

- Node.js 18 以上（ほかに入れるものはありません。`npm install` も不要）
- 動画を書き出すフォルダ（下の「フォルダの決まり」）

## 起動

```bash
node review-tool/server.mjs
```

起動すると `http://localhost:5178` を開けます。Windows なら `レビューツールを開く.bat` をダブルクリックでも起動します（起動済みならブラウザを開くだけ）。止めるときはサーバーの窓を閉じます。

サーバーのファイル（`server.mjs`・`lib.mjs`）を変えたら起動し直してください。画面のファイル（`public/`）は再読み込みだけで反映されます。

## 設定

優先順：起動引数 → 環境変数 → `review-tool/config.json` → 既定値

| 項目 | 起動引数 | 環境変数 | 既定値 | 意味 |
|---|---|---|---|---|
| root | `--root` | `REVIEW_ROOT` | review-tool の1つ上 | 動画と構成メモを探す作業フォルダ |
| inbox | `--inbox` | `REVIEW_INBOX` | `review-tool/inbox` | Claude への依頼を置くフォルダ |
| port | `--port` | `REVIEW_PORT` | `5178` | 待ち受けるポート |
| host | `--host` | `REVIEW_HOST` | `127.0.0.1` | 待ち受けるアドレス |
| videoFolders | — | — | `["out"]` | この名前のフォルダにある動画だけ一覧に出す（`[]` ならどこでも） |

Claude と連携するなら、`listen.mjs`・`claude.mjs` も同じ受付箱を見る必要があるので、**起動引数ではなく `config.json` に書く**のがおすすめです（見本：`config.example.json`）。

画面右上の「設定」からは次を変えられます。

- **この端末だけ**：あなたの名前（メモとコメントに付きます）、見た目（端末に合わせる／ダーク／ライト）、メモ保存後に続きを再生するか
- **作業フォルダ（みんな共通）**：上のバーに出す名前、メモの分類（名前と色）。`<root>/.reviewtool.json` に保存されます

## フォルダの決まり

```
<作業フォルダ>/
  <案件>/
    plan/<名前>_v1.plan.json        構成メモ（保存のたびに plan/.history/ に1つ前が残る・最新30件）
    video/out/<名前>_v1.mp4         動画（videoFolders の名前のフォルダに置く）
    video/out/<名前>_v1.review.json メモ本体（画面が書く）
    video/out/<名前>_v1.review.md   メモの読みやすい版（画面が書く）
    video/out/<名前>_v1.review/     メモの画像
    out/<名前>_v1.jpg               静止画（videoFolders の名前のフォルダの直下に置く。png・jpg・webp）
    out/<名前>_v1.imgreview.json    画像のメモ本体（画面が書く）
    out/<名前>_v1.imgreview.md      画像のメモの読みやすい版（画面が書く）
    out/<名前>_v1.imgreview/        送るときに作る全体図（番号の印つき）
```

- 動画の名前を `名前_v1.mp4`・`名前_v2.mp4` のように版番号付きにすると、「前の版」タブで前の版のメモと Claude の返事を見比べられます
- 静止画も `名前_v1.jpg`・`名前_v2.jpg` と版番号を付けると版ボタンに並びます（別案は `v2b` のような枝番）。同じ名前の `.png` と `.jpg` は同じ絵として扱い、一覧には `.jpg` だけ出ます。`check` で始まるフォルダと `compare_` で始まるファイルは一覧に出ません
- 開けるファイルは作業フォルダの中の動画・画像・音声だけです

## Claude Code との連携

1. **受信口を常駐させる**：Claude Code の Monitor（またはターミナル）で `node review-tool/listen.mjs` を動かしておきます。数秒おきに `inbox/.alive` を更新するので、画面の右上が「Claude 待機中」になります。依頼が届くと1行出力します：
   ```
   📨 レビュー依頼 20260929142523_jvqv：案件/video/out/名前_v3.mp4 メモ1件（やまだ）／ひとこと「…」 → node review-tool/claude.mjs show 20260929142523_jvqv
   ```
2. **Claude がやること**（`claude.mjs`）

   | コマンド | すること |
   |---|---|
   | `node review-tool/claude.mjs pending` | まだ終わっていない依頼の一覧（取りこぼし確認） |
   | `node review-tool/claude.mjs show <依頼id>` | 依頼の中身（メモ・画像のパス・送った人・ひとこと） |
   | `node review-tool/claude.mjs progress <依頼id> "書き出し中…"` | 進み具合を画面に出す |
   | `node review-tool/claude.mjs reply <依頼id> <メモid> "返事"` | メモ（構成メモならコメント）に返事を付けて対応済みにする |
   | `node review-tool/claude.mjs done <依頼id> "まとめ" [新しい動画（画像）の相対パス]` | 完了。新しい動画・画像を渡すと画面に「新しい版」が出る |

3. **構成メモの依頼**（`kind: "plan"`）が来たら：`show` でコメントを読み、`<案件>/plan/*.plan.json` を読みます。書き換えた行は `edited: true`（元の文は `base`）、足した行は `base: null`、消した行は `removed`、並べ替えは `origOrder` と比べると分かります。コメントに `reply` し、同じファイルを直して保存すれば画面は自動で読み直します。直した内容を「新しい元」にするときは、各行の `base` を今の `text` にし、`removed`・`origOrder`・`baseTitle`・`baseIntro`・`sentSig` を消してください
4. **画像の依頼**（`kind: "image"`）が来たら：`show` に出る**全体図**（番号の印を描き込んだ縮小版）をまず見て、各メモの場所（`#番号 右上（横84〜100%・縦3〜54%）／元画像の画素 x…・y…`）と照らします。直したら各メモに `reply`、新しい版番号で書き出して `done <依頼id> "まとめ" <新しい画像の相対パス>`
5. Claude に確認したいことがあるときは、構成メモの行の `comments` に `{ "id": "…", "by": "claude", "text": "…" }` を足すと画面に Claude の吹き出しで出ます

プロジェクトの `CLAUDE.md` に書いておくとよいこと（ひな形）：

```markdown
## レビューツール
- 作業中は受信口を常駐させる：Monitor で `node review-tool/listen.mjs`（切れたら張り直す）。始めに `node review-tool/claude.mjs pending` で取りこぼし確認
- 📨が来たら：`claude.mjs show <id>` → 画像も読む → `progress` で進捗 → 直す → 各メモに `reply` → 書き出し → `done <id> "まとめ" <新しい動画の相対パス>`
- 直した動画は新しい版番号で書き出す（`名前_vN.mp4`）。前の版とメモは残す
```

## ほかの人と使う

サーバーは既定で自分のPC（`127.0.0.1`）だけで待ち受けます。**ログインの仕組みはない**ので、インターネットへそのまま公開しないでください。

- **おすすめ：Tailscale**。`tailscale serve --bg --https=8447 http://127.0.0.1:5178` とすると、同じ tailnet の端末（スマホ・一緒に作る人）だけが `https://<PC名>.<tailnet>.ts.net:8447/` で開けます
- 同じ LAN の中だけで使うなら `--host 0.0.0.0` で起動し、`http://<PCのIP>:5178` を開いてもらいます（LAN の誰でも見られる点に注意）
- 名前は端末ごとに設定するので、誰のメモかは一覧とClaudeへの依頼に残ります
- 書き込み（メモ・構成メモ・Claudeへの依頼）は JSON の送信しか受け付けないので、ブラウザで開いたほかのサイトからこっそり依頼を送り込まれることはありません

## 画面の操作（画像レビュー）

| 操作 | すること |
|---|---|
| 画像の上をなぞる | 範囲のメモ |
| 画像の上を押す | 点のメモ |
| 印を押す → もう一度押す | 選ぶ → 書き直す |
| `Enter` / `Esc` | メモを保存 / やめる（改行は `Shift+Enter`） |
| `N` / `P` | 次・前のメモへ |
| `C`（押している間） | 前の版を表示 |
| `H` | 印を隠す・出す |
| `1` / `2` / `0` | 全体・2倍・原寸 |
| `Ctrl+Enter` | Claude に送る |
| `/` | 画像を選ぶ |

印の色：オレンジ＝まだ送っていない／茶＝送信済み／緑＝対応済み。リンク：`/image?i=<画像の相対パス>`

## 画面の操作（動画レビュー）

| キー | 操作 |
|---|---|
| `Space` / `K` | 再生・一時停止 |
| `M` / `Enter` | ここにメモ |
| `←` `→`（`Shift` で 0.1秒） | 1秒もどる・すすむ |
| `J` / `L` | 5秒もどる・すすむ |
| `,` / `.` | 1コマもどる・すすむ |
| `N` / `P` | 次・前のメモへ |
| `[` / `]` | 再生速度を下げる・上げる |
| `F` | 全画面 |
| `/` | 動画を選ぶ |
| `?` | 使い方 |

メモを書いている間：`Enter` 保存（改行は `Shift+Enter`）／`Esc` やめる／`Alt+1〜9` 分類／`Alt+←` `Alt+→` 0.5秒ずらす／`Alt+R` ここまでを範囲に。構成メモの操作は画面の `?` で出ます。

指で使うとき（スマホ・タブレット）：

| 操作 | すること |
|---|---|
| 動画を1回タップ | 再生・一時停止 |
| 動画の左・右をダブルタップ | 5秒もどる・すすむ（続けてたたくと足される） |
| 動画の真ん中をダブルタップ | 全画面 |
| メモを右へ払う | 対応済みにする（もう一度で戻す） |
| メモを左へ払う | 削除（すぐ「元に戻す」が出ます） |
| 前の版のメモを右へ払う | 「直ってた」にする |
| 構成メモの行の左端 ⠿ をなぞる | 並べ替え |

ボタンの多くはアイコンだけです。マウスを乗せると説明が出ます。

リンク：`/?v=<動画の相対パス>&t=<秒>` でその動画のその時刻を開けます。

## データの扱い

- 保存はすべて「一時ファイルに書いてから置き換え」なので、途中で止まっても壊れにくくなっています
- メモは1件ずつ保存するので、スマホとPCで同時に書いても消し合いません。サーバーに届かなかった変更は、画面を開いている間は覚えておき、つながったら送り直します（閉じる前に知らせます）
- 構成メモは、開いている間に Claude や別の端末が書き換えていたら上書きせずに知らせます（最新を読み込む／自分の変更で上書き）
- `.review.json`・`.review.md`・`.imgreview.json`・`.imgreview.md`・`.plan.json` は Git で記録してよいファイル、`.review/`・`.imgreview/`（画像）・`inbox/`・`plan/.history/` は記録しなくてよいファイルです

## うまく動かないとき

- **「ポート 5178 はすでに使われています」**：起動済みです。`http://localhost:5178` を開いてください
- **動画が一覧に出ない**：`videoFolders` の名前のフォルダ（既定は `out`）に置いてあるか、作業フォルダ（起動時に表示）の中か確かめてください
- **右上が「Claude オフライン」**：`listen.mjs` が動いていません。送った依頼は受付箱に残り、あとで `claude.mjs pending` で拾えます
- **画面が古いまま**：ブラウザで再読み込みしてください（画面のファイルはキャッシュしていません）
